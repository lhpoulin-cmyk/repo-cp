# Repository fleet control plane

`repo-cp` is intended to inventory the Helix-ARPA repository fleet, validate
Foundation-defined conformance, detect drift, and propose narrow remediation.
Foundation defines conformance; each `*-cp` retains its domain authority.
Louis retains approval, merge, exception, and ultimate authority.

Bootstrap status: **BLOCKED — required Foundation operator-action authority
is absent.** No repository is enrolled and no conformance or execution
capability is implemented. The default remains report-only.

The [Foundation handoff](docs/handoffs/foundation-operator-action.md) records
the verified revisions, missing authority, existing related implementations,
and requirements for resuming. Its separate machine-readable repository and
doctrine pins are observations, not acceptance of an unavailable contract.

No live infrastructure, credentials, peer operational actions, or peer edits
are authorized by this repository. Publication of the handoff does not open
an execution gate.
